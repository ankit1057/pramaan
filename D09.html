The story

In 1736, the historic city of Königsberg in Prussia was divided by the Pregel River into four landmasses connected by seven picturesque bridges. Citizens debated a lively weekend riddle: could a person walk through the city crossing each of the seven bridges exactly once and return to the starting point? Leonhard Euler approached the problem not by tracing thousands of individual walking routes, but by abstracting away the physical geography of riverbanks and bridges into discrete points and lines. He replaced the landmasses with vertices and the bridges with edges, inventing the mathematical field of graph theory.

Euler proved that traversing every edge exactly once (an Eulerian circuit) is possible if and only if every single vertex has an even degree (number of connected edges). Since the four landmasses of Königsberg had degrees 3, 3, 3, and 5, the stroll was mathematically impossible. Two centuries later, computer scientists transformed Euler's topological abstractions into algorithmic traversal engines: Breadth-First Search (BFS) for unweighted shortest paths and network broadcasting, and Depth-First Search (DFS) for cycle detection, topological dependency ordering, and compilers.

Say it simply

A graph is a network of points called vertices (or nodes) connected by lines called edges. If edges have arrows, the graph is directed (like Twitter follows); if edges are two-way roads, it is undirected (like LinkedIn connections). Traversing a graph means visiting every node systematically. Breadth-First Search (BFS) spreads outward like a ripple in a pond, visiting all immediate neighbors before going deeper, which always finds the shortest path in unweighted networks. Depth-First Search (DFS) charges down a single path as far as possible before backtracking, making it ideal for detecting cycles and resolving build dependencies.

Say it precisely

Formally, a graph $G = (V, E)$ consists of vertices $V$ and edges $E \subseteq V \times V$. Representation: - Adjacency list: Array or dictionary of lists, consuming $O(|V| + |E|)$ memory. - Adjacency matrix: 2D boolean array $A \in \{0, 1\}^{|V| \times |V|}$, consuming $O(|V|^2)$ memory.

Breadth-First Search (BFS): Maintains a FIFO queue $Q$ and visited set $S$. Discovers vertices in non-decreasing order of distance from source $s$, computing shortest unweighted path lengths $\delta(s, v)$ in $O(|V| + |E|)$ time.

Depth-First Search (DFS): Uses recursion or a LIFO stack. Vertices undergo state transitions: $$\text{WHITE (unvisited)} \to \text{GRAY (active on call stack)} \to \text{BLACK (finished)}$$ - A directed graph contains a cycle if and only if DFS encounters a back-edge to a GRAY vertex. - In a Directed Acyclic Graph (DAG), post-order reverse DFS or Kahn's in-degree queue algorithm produces a topological sort satisfying: $$\forall (u, v) \in E, \quad \text{pos}(u) < \text{pos}(v)$$

A graph is bipartite if and only if it contains no odd-length cycles, verifiable via 2-coloring.

Why it's true

Understanding graph traversal guarantees requires proving why BFS finds shortest paths and why 3-color DFS correctly detects cycles in directed graphs. First, let us prove that BFS computes shortest path distances $\delta(s, v)$ on unweighted graphs. Suppose we run BFS from source $s$. Let $d[v]$ be the distance assigned to vertex $v$ when it is pushed onto the queue. We claim that vertices are dequeued in monotonically non-decreasing order of distance: if $u$ is dequeued before $v$, then $d[u] \le d[v]$.

We prove this by mathematical induction on queue operations. Initially, only $s$ with $d[s] = 0$ is in the queue. Suppose the invariant holds. When vertex $u$ is dequeued, all its unvisited neighbors $w$ are assigned $d[w] = d[u] + 1$ and enqueued. Because all existing vertices in the queue have distance at least $d[u]$, any newly enqueued neighbor has distance at most 1 greater than the current queue maximum. Therefore, the queue always consists of vertices with distance $k$ followed by vertices with distance $k+1$. Because distances only increase monotonically, the first time a vertex $v$ is discovered, the path traversed must have minimal edge count, proving that $d[v] = \delta(s, v)$.

Next, consider cycle detection in directed graphs. A naive approach of checking whether a node has been visited fails because cross-edges or forward-edges can reach previously processed vertices without forming a cycle (e.g. diamond DAG $A \to B \to D$ and $A \to C \to D$). To unambiguously distinguish cycles from non-cyclic converging paths, DFS colors vertices with three distinct states: 1. WHITE: Unvisited node. 2. GRAY: Currently being explored and actively present on the recursion call stack. 3. BLACK: Fully explored with all descendant branches exhausted.

If DFS at vertex $u$ encounters an edge $(u, v)$ where $v$ is GRAY, vertex $v$ is an active ancestor of $u$ on the current call stack. Following the path of call stack edges from $v$ down to $u$, combined with the edge $(u, v)$, forms a closed directed loop $v \to \dots \to u \to v$, proving with absolute mathematical certainty that a directed cycle exists. If $v$ is BLACK, its exploration finished in an earlier branch, representing a cross-edge or forward-edge in a DAG.

Oracle lab

The ground truth for graph traversals rests on topological invariants and cycle classification theorems. For a Directed Acyclic Graph (DAG), Kahn's algorithm serves as a formal verification oracle: if the topological sort output contains exactly $|V|$ vertices, the graph is provably acyclic and all dependencies are satisfied; if the output contains fewer than $|V|$ vertices, an unresolved cycle exists. In undirected bipartite testing, 2-coloring must assign opposite colors to all edge endpoints without conflict.

          Misconceptions
            

          • "BFS and DFS explore the same number of nodes on any graph." While both visit all reachable nodes $O(V + E)$ in total, their traversal orders differ fundamentally. BFS expands level by level finding shortest paths; DFS plunges deep and is prone to stack overflows on deep line graphs.
            • 

          • "Cycle detection in directed graphs can be done simply by checking if a node was already visited." Visiting an already explored node can happen via cross-edges in a DAG. Directed cycle detection strictly requires detecting back-edges to nodes actively present on the recursion call stack (GRAY nodes).
            • 

          • "A topological sort always exists for any graph." Topological sort exists if and only if the graph is a Directed Acyclic Graph (DAG). If any directed cycle exists, no linear ordering can satisfy all prerequisites.
            • 

          • "Bipartite graphs can have triangles." A graph is bipartite if and only if it contains no odd-length cycles. A triangle has length 3 (odd), which strictly violates 2-colorability.
            • 

          Where it breaks
          Traversals break down on massive scale-free web graphs (billions of nodes like Google's web crawler or Facebook's social graph). Storing adjacency lists in RAM becomes impossible, and recursive DFS crashes with call stack overflows. Industrial search engines solve this using External Memory Graph Traversals, Pregel/BSP (Bulk Synchronous Parallel) distributed message passing, and PageRank random-walk matrix power iterations.
          In your real work
          Build systems like Make, Gradle, and Bazel use topological sorting to construct compilation dependency DAGs. Package managers (npm, pip, pub) run cycle detection and Tarjan SCC to identify circular dependencies. Compilers construct Control Flow Graphs (CFGs) and use dominator trees derived from DFS to optimize loop invariants and dead code elimination.
          Flash cards
          Why does BFS guarantee shortest paths in unweighted graphs?
          Because vertices are discovered in non-decreasing order of distance from source: all vertices at distance $k$ are processed before any at $k+1$.
          What do the three colors (WHITE, GRAY, BLACK) signify in directed DFS?
          WHITE = unvisited, GRAY = currently on the active recursion call stack, BLACK = fully explored with all descendants finished.
          What indicates a cycle during directed DFS?
          Encountering an edge leading to a GRAY vertex (a back-edge to an active ancestor on the call stack).
          What condition proves an undirected graph is bipartite?
          The graph is 2-colorable with zero adjacent nodes sharing the same color, which is mathematically equivalent to having no odd-length cycles.
          How does Kahn's algorithm detect cycles in a directed graph?
          If the number of vertices dequeued with in-degree 0 is less than total vertices $|V|$, the remaining vertices form a directed cycle.
          What does low[u] represent in Tarjan's SCC algorithm?
          The lowest discovery time reachable from $u$ through its subtree and at most one back-edge to an active stack ancestor.
          Stop when
          You can implement 3-color directed cycle detection, Kahn's topological sort, and Tarjan's SCC algorithm with complete confidence and zero errors.
